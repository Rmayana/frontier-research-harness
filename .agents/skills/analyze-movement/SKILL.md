# 영상에서 관찰 가능한 주장 만들기

- 공개 원본을 찾아야 하면 Exa로 후보를 찾고 원 출처·판본·재편집 여부를 확인한다. 웹페이지 설명으로 동작을 추정하지 않는다. 재생 가능한 자료가 없으면 접근 가능한 구간이나 사용자가 제공한 파일로 범위를 좁힌다.
- 사용자가 분석을 요청한 로컬 파일을 비공개 `records/inbox`에서 연다. 원본이 다른 곳에 있다면 비공개 복사본을 사용하고 원본은 보존한다. 같은 이름의 기존 자료는 덮어쓰지 않는다.
- `inspect_video(filename="session.mp4")`로 재생 시간과 영상 정보를 확인한다. `inspect_video(filename="session.mp4", seconds=3.2)`로 프레임을 열고 관찰한 시각을 남긴다. 동작의 시작·종료를 비교하려면 양쪽 구간을 확인한다. 가변 프레임률 영상은 실제 타임스탬프를 따른다.
- 연속 구간의 추정이 필요하면 로컬 MediaPipe, 수동 보정이 필요하면 Kinovea를 선택한다. 측면 시야, 관절 가림, 거리 기준, 카메라 이동을 살핀다. 보정 기준이 없으면 시간이나 상대 궤적처럼 확인 가능한 양으로 범위를 좁힌다. 개인 영상의 외부 처리는 자료·목적·서비스를 사용자와 확인한 후 진행한다.

**반환**은 파일 또는 공개 원본 식별자, 시각 구간, 직접 관찰, 측정 조건과 불확실성이다. 왜 그 훈련을 했는지 또는 효과가 있었는지는 별도의 문헌·비교 질문으로 넘긴다. [로컬 도구 위치](../../../docs/TOOLS.md)
