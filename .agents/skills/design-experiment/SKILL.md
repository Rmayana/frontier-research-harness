# 판별 가능한 실험 선택

연습한 리듬에서 점수가 오른 상황이라면 과제 친숙도와 새로운 과제로의 전이가 같은 결과를 예측한다. 기존 기록에 동등 난도의 미노출 과제가 있는지 먼저 확인한다. 차이를 가를 자료가 없으면 어떤 새 측정에서 두 설명의 예측이 갈리는지 제안한다.

- 실행 전에 주된 지표와 단위, 평가 시점, 비교 조건, 수행량, 판정 보류 조건을 정한다. 책임자는 원예측을 `append_record`의 prediction으로 보존한다. 사용자가 수련을 채택한 시점은 별도로 기록한다.
- 이미 측정한 값이면 `run_analysis(baseline=[6,7], followup=[7,8], unit="점", paired=true)`처럼 계산한다. paired는 실제로 같은 과제·대상·조건으로 대응되는 값에만 사용한다. 단위, 누락, 반복 측정의 독립성, 과제 선행 노출을 먼저 검토한다. 계산은 관측 변화의 근거다. 원인을 특정하려면 비교 설계가 뒷받침해야 한다.
- 역학적 가정이 결론을 좌우하면 로컬 OpenSim, 최적 제어 문제가 정의되면 Moco를 검토한다. 입력 좌표·동기화·외력·모델 가정과 기준값을 확인한다. 필수 입력이 없는 상황에서는 식별할 수 있는 더 단순한 비교를 선택한다. 실행 경로는 [도구 안내](../../../docs/TOOLS.md)에 있다.
- 결과가 다르면 입력 오류, 측정 조건 변화, 모델 한계, 가설 실패 중 어느 쪽을 구분할 수 있는지 점검한다. 원래 예측, 결과, 다음 조사를 연결해 반환한다. 결과를 보고 만든 가설은 후속 비교용으로 남긴다.
