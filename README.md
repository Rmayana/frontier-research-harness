# 수련 연구 에이전트

현실의 과학 법칙 안에서 더 뛰어난 수련 방법을 연구하고, 실제 수행 결과로
설명·공법·개인 모델을 발전시키는 AI를 만든다.

현재 단계: 확정한 하네스 구조를 기준으로 아키텍처 설계를 다시 진행한다. 상세 기술 설계와 구현은 아직 시작하지 않았다.

확정 구조: 외부 하네스 ↔ Codex SDK / App Server / CLI ↔ Codex Core.
사용 구조: 인터페이스 ↔ 하네스 ↔ 모델. 모델 실행에는 기존 Codex 구독 사용량을 사용한다.

- [현재 요구사항](docs/SPECIFICATION.md): 목표·범위·지능적인 연구·협업·제약·첫 버전·미정 사항의 기준.
- [기능 설계](docs/FUNCTIONAL_DESIGN.md): 연구·수련 및 에이전트 운영 기능의 동작 흐름·연결·확인 방법. 아키텍처 설계의 입력이며 세부안은 함께 보완한다.
- [작업 지침](AGENTS.md): 대화를 문서와 개발 작업에 반영하는 원칙.
- [하네스 구조](docs/ARCHITECTURE.md): 확정한 하네스 구성도와 인터페이스·하네스·모델 사용 구조.

2026-10-30 새 요구사항으로 다시 시작하기 위해 기존 코드·설계·조사 문서를
정리했다. 이전 커밋은 Git 이력에서 확인할 수 있으며 현재 설계로 승계하지 않는다.

## 문서 관리

- 논의 중인 후보는 우선 채팅에서 비교한다. 확정된 요구는 명세에 갱신한다.
- 새 문서는 필요한 단계에서 역할과 범위를 논의한 뒤 만든다. 질문마다 파일을 만들지 않는다.
- 합의 내용이 파일에 저장됐는지, Git 커밋과 GitHub 반영까지 됐는지 구분해 보고한다.
- GitHub는 공개 저장소다. 개인 원본 영상·몸 상태·측정 기록과 비밀정보는 올리지 않는다.
