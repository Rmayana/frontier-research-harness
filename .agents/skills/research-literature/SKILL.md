# 연구 질문에서 원문까지

먼저 어떤 결정에 쓸 근거인지 잡는다. 효과를 묻는다면 대상·중재·비교·평가 지표를 정리하되 탐색 질문에 이 형식을 강제하지 않는다.

| 필요한 자료 | 첫 경로 | 이어갈 조건 |
| --- | --- | --- |
| 수련 효과와 적용 대상 | `search_papers(query="motor learning transfer", provider="europepmc")` 또는 pubmed | 효과를 좌우하는 비교 조건이 초록에 없으면 PMCID로 원문을 연다. 초록 확인에는 PMID를 쓴다. |
| 후속 연구·반례·새 결과 | openalex, sportRxiv의 공급자 이름 `sportrxiv`, 시간 조건을 넣은 europepmc, 분야별 arxiv-feed | 같은 DOI와 원 연구를 합치고 프리프린트·출판본·후속 데이터를 연결한다. 철회 의심 시 retractions를 검색하고 고지의 대상 DOI를 대조한다. |
| 특정 측정 자료·등록·지역 문헌 | datacite, WHO ICTRP 공개 포털, jstage | 등록된 결과변수와 보고된 지표를 맞춰 본다. 링크만 받은 결과는 원문 열람 상태를 따로 표시한다. |

`read_source(source_id="PMID:31452104")` 형태로 식별자를 전달한다. 원문은 `PMC…`를 쓴다. 발췌가 잘렸으면 반환된 다음 위치를 읽는다. PDF 표의 분모·각주가 결론을 바꾸면 로컬 PDF에서 해당 페이지를 확인한다. 접근 실패 시 다른 공개 판본을 찾고 실제로 확인한 범위를 보고한다. 계정 제한과 429는 결과 0건과 구별한다.

책임자에게 **확인한 주장 / 원문 좌표와 판본 / 반대 근거 / 내 조건에 옮길 때 남는 차이**를 돌려준다. 개인 사례가 검색어에 드러날 때는 일반화된 공개 용어를 우선한다. 접근 환경과 대체 경로는 [도구 안내](../../../docs/TOOLS.md)를 참고한다.
