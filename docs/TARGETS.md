# 전신 목표 수치 표

사용자가 제공한 Human Frontier v2의 **연구 목표 수치**를 원문 그대로 정리했다.
수치 보존은 출처 검증이나 동시달성 입증을 뜻하지 않는다. 첨부문 자체도 관측치·상향 탐색 목표·기능 제약을 구분한다.
최적화는 이 표의 모든 숫자를 개별 최고로 만드는 것이 아니라, 같은 몸의 결과를 [동일 가중 종합점수](SCORECARD.md)로 비교하는 것이다.

원문과 설명·시험 조건·19개 출처 링크: [첨부 원문 보존본](references/frontier-v2-user-source.md).
원문의 관측값은 **원문 주장, 이번 작업에서 외부 검증하지 않음**이다. 화살표는 점수 변환 검토를 위한 표시이며 무제한 생물학적 향상을 가정하지 않는다.
범위는 임의로 중간값이나 한쪽 끝을 택하지 않고 보존했다. 동일 지표의 다른 시험 조건은 구별하고, 동일 측정의 반복은 중복 가산하지 않는다.

## X. 전체 회복력

원문 복합 회복 지표: `R24 = (CMJ24 + Force24 + Sprint24 + HRV24) / 4`, `R24 ≥ 98`, `R48 = 100±2`. 각 값의 baseline을 100으로 두는 제안이다.

시간형 Sprint는 방향 보정, HRV는 기준 범위 해석이 필요하다. 구성 요소와 이 복합값을 함께 종합점수에 더하면 중복 가중되므로, X는 참고용으로 보존한다.
