# Domain Docs

This is a single-context repository. Engineering skills use the root glossary and system-wide architectural decisions.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read relevant decisions under `docs/adr/` when that directory exists.
- Proceed silently when no relevant ADR exists.

## Language

Use terms exactly as defined in `CONTEXT.md` in specifications, tickets, tests, and implementation discussions. Reconsider an unlisted synonym before introducing a new domain term.

## Decisions

Surface any conflict with an existing ADR explicitly. Domain terms are added to `CONTEXT.md` when resolved; hard-to-reverse architectural tradeoffs are recorded under `docs/adr/` only when a real decision requires them.
