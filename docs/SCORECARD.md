# 동일 가중 종합점수 표

[목표 수치 표](TARGETS.md)의 연구 목표와 모델 결과를 나란히 비교한다. **부분 조건 계산과 공개 관측자료 비교는 실행했으며, 전신 최적 조합과 전신 종합점수는 아직 미산출이다.** 원래 목표와 현재 결과·검토안을 나란히 정리한 [전체 비교표](../data/personal/research-2026-09-10-target-review/REPORT.md) 및 [검색 가능한 표](../data/personal/research-2026-09-10-target-review/target-comparison.html)를 참조한다. 조건부 범위는 승인된 새 목표가 아니다.

## 계산 원칙

비교 집합에 포함한 서로 다른 지표 N개에 각각 가중치 `1/N`을 적용하고, `S = Σ sᵢ / N`을 최대화한다.
범주별 평균을 다시 평균내지 않는다. 지표 수가 많은 범주에 임의로 추가 보정 가중치를 주지도 않는다.

| 지표 유형 | 변환 원칙 | 적용 조건 |
|---|---|---|
| 높을수록 좋은 양수 비율척도 | `s = 100 × x/t` | 기준 t>0, 단위·시험 조건 일치. 성능 기준 초과는 100점 이상 허용 |
| 낮을수록 좋은 양수 비율척도 | `s = 100 × t/x` | x>0, t>0. 허용 하한과 모델 범위 필요; 0 근처 발산을 최적값으로 취급하지 않음 |
| 적정 범위형 | 범위 안의 기준 점수 100; 범위 밖 손실 함수는 미정 | 숫자 범위와 감점 폭을 근거 없이 임의 확정하지 않음 |
| 목표 0·음수 변화량·Z-score·서열 척도 | 의미에 맞는 별도 무차원 변환 필요 | 0 또는 음수로 나누거나 서로 다른 척도를 같은 비율로 취급하지 않음 |
| 구조·생리·시험 입력 | 수행과의 관계 및 평가 형태를 먼저 명시 | 큰 수를 자동 보상하지 않음; 제외 여부도 기록하고 후보 간 동일하게 적용 |

기준 대비 같은 비율에 같은 점수를 준다는 의미의 공평함이다. 동일 가중치가 같은 생물학적 난이도나 실생활 가치를 보장하지는 않는다.
정규화 기준·지표 집합·변환·허용 범위를 정하면 비교 중 고정한다. 정의가 바뀌면 같은 정의로 모든 후보를 다시 계산한다.
건강·물리·모델 적용범위 제약은 별도로 명시한다. 제약을 만족하는 후보 사이에서는 일부 지표 감소를 다른 지표 증가로 상쇄할 수 있다.
미예측값은 0점·기준값·평균값으로 채우지 않는다. 미예측 지표를 뺀 부분 평균을 전신 종합점수로 부르지 않는다.

## 조합별 종합 결과

| 비교 조합 | 체중 | 고정한 지표 집합·변환 버전 | 모델·입력·실행 기록 | 지표별 원점수·환산점수 | 동일 가중 종합점수 | 제약·불확실성 | 순위 |
|---|---|---|---|---|---|---|---|
| 실제 기준 조합 | 미입력 | 미확정 | 미실행 | 미계산 | **미계산** | 미평가 | 없음 |
| 탐색한 최고 조합 | 미산출 | 미확정 | 미실행 | 미계산 | **미계산** | 미평가 | 없음 |

반복 실행이 생기면 후보별 실제 값과 결과 기록을 추가한다. 모델·탐색 범위 안에서 가장 높은 결과와 전역 최대값의 입증, 실제 인체의 달성은 구분한다.
아래 표의 ‘미계산’은 결과가 없는 상태이며 점수 0이 아니다. 지표의 최종 독립성·변환을 확정하기 전에는 N을 정하지 않는다.
